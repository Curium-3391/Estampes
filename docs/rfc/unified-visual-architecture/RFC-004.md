# RFC-004 — Workbench / Panels / Viewports

Status：**Proposed Architecture**。Current Implementation：`workbench.js` single static canvas、`surface/store.js` hashed canvasKey、`service.js` open/close/reconcile，見 [AUDIT](AUDIT.md)。Open Decision：OD-04 Host protocol與實測；Future Extension：pop-out/跨瀏覽器低延遲協作，不要求外站。

## State Ownership / Interfaces

| Component（Proposed file） | Owns / public interface | 禁止 |
| --- | --- | --- |
| DocumentStore (`public/visual/document-store.js`) | Map docId→immutable snapshot/revision；`get,subscribe,hydrate,dispatch,reconcile,release`，widget內一份；pending command結果 keyed commandId | camera、DOM、跨doc可變alias；把tool payload當未驗證op執行 |

| Viewer (`viewer.js`) | root element、SVG groups/caches、ResizeObserver、rAF、AbortController；`mount(renderPlan),suspend,resume,dispose` | 透過全域#surface查其他Viewer；擁有persistent document |
| PanelInstance (`public/panels/visual-panel.js`) | panelId、binding、viewer/controller handle、focus/accessibility、loading/error UI | 因close呼叫deleteDoc；隱式打開最末Graph當target |

| Server DocumentService/ReferenceService | validation/auth/OCC、snapshots、content commands、refs；RFC002/005 | 以Panel state作授權來源 |

Tool state與selection屬controller；selection可跨同Scene多objects但不跨document；keyboard shortcuts只送focused viewer，input/textarea保留文字編輯。Calculator維持按panel instance分開state/notebook；Graph和image均factory mount shared Viewer，不複製HTML script。safe DOM factories、MathML allowlist可沿用。

## Persisted Surface / Viewport Schemas

```ts
interface SurfaceV2 {
  schema:'estampes.surface/2';surfaceId:string;revision:number;
  workspaceId?:string; // legacy canvasKey only in compatibility metadata
  panels:PanelRecord[]; viewports:ViewportRecord[];
  layouts:{desktop:Layout;tablet:Layout;mobile:Layout};
}
type PanelRecord = {id:PanelId;module:string;descriptorId:string;open:boolean;
  binding:{kind:'viewport';viewportId:ViewportId} |
          {kind:'notebook';notebookId:string} | {kind:'none'} };
type ViewportRecord = {id:ViewportId;documentId:DocumentId;sceneId:SceneId;
  presets:Record<'desktop'|'tablet'|'mobile',{
    camera?:{centerDu:number[];zoom:number;rotation:number};
    hiddenLayerIds:string[];overlays:ViewportOverlay[]}>};
```

`viewportId`是persistent slot；runtime identity是(widgetInstanceId,viewportId,bindingGeneration)，所以兩個widget開同slot不共享pointer/camera。persisted camera僅initial preset，explicit「記住視圖」以Surface revision提交，不每次pan都跨widget同步；widgetState可記自己的last camera（有界、只含IDs/preferences，無secrets）。hidden overrides/HUD可explicit save preset並在該widget即時顯示，其他widget不強制重設當前camera。selection、draft points、tool mode、history cursor、hover、pointer captures永不寫surface。preferences更新不提升Document revision。

Panel binding change：`unbound → loading → mounted → suspended → mounted → closed`；bindingGeneration每次bind/unbind+1。close先cancel gestures、pending view render，保存可回復draft於DraftStore提示，再dispose Viewer/訂閱；保留PanelRecord open=false、ViewportRecord及Document。remove PanelRecord為explicit UI cleanup，只刪binding record，無doc cascade。重新open可選既有closed instance或明確new instance，不能以同descriptor自動換Doc。document archived時viewer readonly tombstone/restore action，非白畫布。

## Update / Subscription Protocol

Proposed transport採既有MCP App-only calls，無新CSP/WebSocket需求：`documents_get_changes`接受有界最多12個`{documentId,sinceRevision}`，回 `{commitId,documentId,baseRevision,revision,changes|snapshotHash,deleted:false}`；缺gap回snapshotRequired。visible widget每2秒poll（scheduler建議，可調），hidden pause；focus、command ACK、tool result redelivery立即reconcile。這是排程規格，不是已測量延遲承諾。Phase3量測poll成本後核准budget；不得承諾exactly-once delivery。

同widget所有viewer共享DocumentStore subscription，doc commit只reducer一次，各viewport以自有camera render。optimistic state若使用只在pending overlay，authoritative snapshot不被本地草稿覆寫。other-widget updates via reconcile到DocumentStore：相同rev/hash忽略，低revision忽略，非連續rev fetch完整snapshot；相同revision不同hash報INTEGRITY_ERROR，不能last writer wins。Document內容同步，selection若target removed清除/轉invalid；camera不follow別的widget。

Mutation required `{commandId, expectedRevision}`；同doc排隊；retries same payload/key可重取result，不在CONFLICT時自動改expectedRevision套用未知位置。Surface layout可以對純layout intent重新base一次，但content drawing不得照抄wbApply的自動retry。cross-store tool response帶commitId與revision vector，reader從同committed manifest取得；不把分開snapshot混成同result。

## Host Lifecycle / Redelivery

Proposed result envelope：`{kind:'estampes.document_surface',schemaVersion:1,resultId,commitId,documentRefs:[{documentId,sceneId,revision}],surfaceId}`；_meta承接widget-only完整geometry/primitives/previews；structuredContent為LLM可讀typed refs/summary，不假定_meta必達。meta missing時使用app-only get snapshot/chunked asset；chunk request帶resource hash/offset，全部拼完驗hash再mount。

HostBridge同時支持MCP Apps notification及openai globals，但只進一個hydration reducer。dedup使用resultId+docRevision+snapshotHash，不能用JS object identity；input after result僅preview忽略，不覆蓋committed snapshot/draft。重送不同meta可補缺asset，不重設camera/selection/unsent marks。message source必為parent、驗JSONRPC shape/knownmethod，origin若可取得固定值就pin；sandbox opaque origin則依MCP handshake+parent reference，不依未證實Host API。

Widget recreate：先restore valid persisted IDs/preferences，再fetchauthoritative revisions，再render；不自動create document/notebook。暫時offline顯最後snapshot+stale，不允聲稱saved；ACK遺失用commandId查狀態，不按重開又送create。RPC timeout清pending並可重試；dispose reject所有pending waiter、release capture、remove listeners、abortfetch；late callback generation不符丟棄。resource URI隨release新增，保留全部legacy URI轉舊adapter/相容bundle；不讓saved conversations找不到資源。

## Error Recovery / Mobile Constraints

保留existing MAX_PANELS=12，calculator max4可沿用，Graph new descriptor max至少3但總panel cap不擴張。Viewer失敗只影響該panel，retry重新取相同document，不生成空檔。Module disabled：其capability buttons停用，已存public content仍由trustedrenderer顯示；unknown viewer kind inert placeholder。web/mobile host resize protocol與display modes需UVA-38/39真機記錄，fake host screenshot不能充當驗收。外部網址僅explicit link，所有普通編輯留widget內。

## Phase 0.1 — Editing / Embed / Authority Integration

Panel/Viewer層只顯示[ANNOTATION-POLICY](ANNOTATION-POLICY.md)server-authorized操作：Unified user可Move/Resize/Restyle/Relayer/Relabel/Delete/Undo/Redo未鎖AI/moduleink；UI不以author決定only-own，也不信client自稱user。每edit帶doc與annotationrevision，userguard阻擋LLM/module後續覆寫。

[EMBED-CONTRACT](EMBED-CONTRACT.md)規定defaultparentdrawing、explicitchildviewportediting與deriveddependencytoken；documents_get_changes回parentdependencyChanged即使parentrev相同，allviewportsre-renderfixedvector。[AUTHORITY-CUTOVER](AUTHORITY-CUTOVER.md)A3顯MIGRATION_BUSY、A6/A7readonly保草稿；flag關閉不能刪doc或切回legacyfiles。
