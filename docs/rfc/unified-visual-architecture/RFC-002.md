# RFC-002 — Document / Scene / Annotation Model

Status：**Proposed Architecture**。Current Implementation：Entry Map與canvas.json見 [AUDIT](AUDIT.md)。Open Decision：OD-01/02；Future Extension：shared mutable objects/Scenes及多user merge。

完整ID grammar、operation欄位與validation、materialized/persisted差異、supportingrecords見[Contract Appendix](CONTRACTS.md)。下方interfaces為readschema；binding權威在committedregistry、Document/Notebook持bindingId，避免兩份可寫status。

## Schema 與 Identity

以下為versioned wire/persistence型別草案，後續PR-1A轉為strict Zod schemas；不在Phase0改正式實作。所有UUID用server生成UUIDv4；import使用mapping。各schema unknown top-level fields拒絕；`extensions`以namespaced鍵保留有界JSON、不可執行；legacy完整raw放隔離sidecar不交module。

```ts
type DocumentId = `doc:${string}`; // canonical UUID, reject other prefixes
type SceneId = `scene:${string}`;
type ViewportId = `vp:${string}`;
type PanelId = `panel:${string}`;
type Ref = { documentId: DocumentId; sceneId: SceneId;
             kind: 'object'|'annotation'|'layer'|'frame'; id: string };
type AssetRef = { assetId: `asset:sha256:${string}`; legacyImageId?: string };
interface VisualDocument {
  schema: 'estampes.document/1'; id: DocumentId; kind: 'image'|'graph';
  title: string; revision: number; state: 'active'|'archived';
  persistence: 'memory'|'durable'; createdAt: string; updatedAt: string;
  defaultSceneId: SceneId; scenes: Scene[];
  bindings: ReferenceBinding[];
  annotationSupport: 'shared-v1';
  provenance: { createdBy: 'user'|'assistant'|'import'|'migration';
    legacySetKey?: string; importedFrom?: string };
  extensions?: Record<string, unknown>;
}
interface Scene {
  id: SceneId; documentId: DocumentId; revision: number;
  extent: { width: number; height: number; unit: 'du' };
  background: { kind:'solid'; color:string } |
    { kind:'asset'; asset:AssetRef; sourceToDocument:number[] };
  layers: Layer[]; objects: SceneObject[]; annotations: Annotation[];
  frames: CoordinateFrame[]; gestureDecisions: GestureDecision[];
  rejections: Rejection[]; interactionEvents: InteractionEventRef[];
  undo: CommandHistory; tombstones: Tombstone[];
}
interface Layer {
  id: string; author: 'user'|'assistant'; name: string;
  module?: string; opacity: number; visible: boolean; locked: boolean;
  content: {kind:'object'|'annotation'; id:string}[];
}
```

Document.revision是所有內容（含layer、mark、object、binding、archive）OCC主軸，initial=1；Scene.revision只在該scene改動時+1供diff/cache，不是接受command的替代。Object.revision/Annotation.revision初始1，每次自身資料變更+1；frame mapping change提升scene/doc revision但不偽稱annotation geometry被改寫。Layer order是Scene.layers array bottom→top，content array order是穩定stacking，不能同時另持order integer權威。legacy layer保留 L<n>，objects o<n>與marks原ID；新local ID使用UUID prefix防相撞。跨doc ref總帶document/scene/kind/id，不能只拿o2。extent finite正數、graph預設1600×1000 du，image以已校正working width/height為du但不依賴該raster存在。

SceneObjects保留現有type/props/label/visibility(public|scratch)/provenance/evidence/revision；新增outer envelope `coordinateFrameId`與local identity。function-plot仍保留expression/domain/labelMode/style，`props.frame`仍指本Scene axes object，adapter轉為frame descriptor，二者由一個axes owner推導而非分開可寫。Graph Document無必要AssetRef，background為solid；embedded image是raster layer asset ref，不是Graph身份。

## Annotation schema：雙領域共用Contract（方案 B）

```ts
interface Annotation {
  id: string; revision: number; type:'point'|'rect'|'arrow'|'polyline';
  layerId: string;
  geometry: { x?:number; y?:number; x2?:number; y2?:number;
    points?:{x:number;y:number}[]; smooth?:boolean; closed?:boolean };
  anchor: Anchor; style: {color?:string;size?:string;pen?:'pen'|'highlighter'};
  label?: string;
  provenance: {author:'user'|'assistant'; grounding:string;
    editedByUser?:boolean; derivedFrom?:Ref; original?:unknown};
  finding?: {note?:string;status?:string;confidence?:string;evidence?:Evidence[];
    ambiguities?:string[];review?:string;reviewReason?:string;
    previouslyRejected?:unknown;findingUpdatedAt?:number};
  stroke?: {order?:number;relativeStartMs?:number;relativeEndMs?:number;
    pointerType?:'mouse'|'pen'|'touch'};
  intentEventIds: string[];
}
interface Evidence {
  observer:'model'|'tool'|'user'; kind:string; says:string;
  source: {kind:'asset';asset:AssetRef;region?:number[]} |
          {kind:'document';ref:Ref;revision:number;region?:number[]};
  original?:unknown; // imported historical claim, never elevate verification
}
```

完整字段migration不能只用`protocolMark`再反解。保留raw `grounding/object/edited/role/derivedFrom/findingUpdatedAt`等由RFC006欄位表映射；stroke時序不變為wall-clock；Arrow指向語義只來自intent，不從形狀猜。gesture candidate可重算，但confirmed/rejected decisions與member mapping須保存；一個stroke不因group變成不可分解shape。InteractionEvents為append-only有界payload store，記錄intent、note、user-provided quote、focus/context、submissionId、documentRevision；Document保留refs，Bundle攜帶明確選擇的visual intent，排除無關聊天與secrets。

| 選項 | 優點 | 代價與拒絕理由 |
| --- | --- | --- |
| A 全統一為SceneObject | 一個CRUD/render型別 | claim/evidence權限、user intent、stroke/review會膨脹通用props，舊工具投影容易丟資料；需全量protocol重寫 |
| B 保留Objects/Annotations，共用Interaction/Layer/Render Contract | existing validators/assessment/Graph保留；型別可證明domain資料完整 | 需要兩個domain adapters與typed content refs；推薦，Phase2加入 shared selection dispatch |
| C Marks轉object但raw sidecar | 視覺簡化 | 雙權威，sidecar無法保證每次編輯同步；只可作migration quarantine，不能正式domain |

## State Ownership / References

一個Annotation與Object只出現在同Scene一個Layer.content一次；content.kind避免mark id=o2撞object。沒有layer legacy資料移入明示 `legacy-unlayered`，不遺失順序，unknown layer進quarantine report。同Document多Scene允許，跨scene anchors V1拒絕，跨scene relation可binding但不可偷偷frame lookup。跨Document不能共用Map、Array或Scene instance；copy deep clone content + new document/scene IDs、保持可用local IDs，內部Refs全映射；link/embed不轉移ownership。

```ts
interface ReferenceBinding {
  id:string; kind:'relation'|'cas-plot'|'embed';
  source:Ref | {notebookId:string;cellId:string;resultId?:string};
  target:Ref;
  mode:'live'|'snapshot'; sourceRevision?:number; targetRevision?:number;
  status:'fresh'|'stale'|'conflict'|'removed'|'unavailable'|'unresolved';
  policy?:'pause-on-user-edit'; provenance?:unknown;
}
```

Ref resolution不代表授權；每read/render traversal都由ReferenceService檢查execution scope，不能藉embed讀出module沒拿到的文件。`removed`只由committed tombstone證明，not-found/offline先unresolved/unavailable。外部unknown ref保留original identity但不查任意URL或按名稱匹配。

## Command Interface / Revision Semantics

```ts
executeDocumentCommand({
  documentId, expectedRevision, commandId, actor,
  operations // annotations.create/update/delete, layers.update/reorder,
             // scene.apply, bindings.update, document.archive/restore
}): Promise<{commitId:string;revision:number;sceneRevisions:Record<string,number>;
  changes:unknown[];replayed:boolean;undoToken?:string}>;
```

actor由authenticated tool path產生，不信caller `author`。相同commandId+canonical payload hash回原結果（含ACK遺失後retry），同key不同hash回IDEMPOTENCY_MISMATCH；OCC mismatch回CONFLICT+currentRevision，草稿不動。V1單process queue per document；跨doc coordinator固定按type+ID排序取得locks，避免死鎖。no-op不提升revision且回noChange；有實質修改commit只+1一次。SceneOps adapter須抑制舊nested revision bumps成為新doc版本權威；輸出保留legacy sceneRevision投影。

## Document / History Lifecycle

Document：`create draft (unpublished) → validate → active(rev1) → archived → active`；draft失敗不對reader可見。memory/durable是部署持久化屬性，不代表清除資格；memory-only host重建後資料可能不可恢復，UI明示。無open panel仍active可在library/list Documents中列出。

存檔runtime：`clean → localDraft → committing → clean`；衝突→`conflicted`保留草稿、失敗→`failed`可重試；只有durable ACK後顯示saved。Panel unmount不能清空localDraft，pending drafts存在widget-scoped DraftStore並明示；跨裝置只復原committed資料，不保證尚未送出的draft。

Undo/Redo為content command history，不是viewport past/future。history記actor、affected refs、before/after hashes、inverse operations、base/applied rev。user可undo自己的command，不能默默undo另一widget已改的內容；compare affected entity revisions，無衝突才提交inverse為新revision。LLM必須使用明確command/undo token，不能假扮user。Redo針對successful undo的forward ops，branch edit清除該actor redo鏈。layer lock、ownership照常驗證；不能透過undo繞過鎖。V1保留60個content commands，超限只截history不刪objects；Phase7依bench可降低可配置上限，不能默默縮減已有保留的legacy undo資料。

## Acceptance / Compatibility

UVA-01–07、14、23–25、31–33為phase1/2/6門檻；legacy evidence原值、ref maps、counts、hash及view render都需驗證。Module或Viewer不得直接呼叫store mutate，不建立第二份mutable document snapshot。New schema exports提供完整domains；legacy visual/2投影有lossReport，遇無法表示的graph/world anchors拒絕lossless export，不捏造img ID。正式ID grammars、limits在PR-1A freeze，不能在Phase4實作時再猜。
