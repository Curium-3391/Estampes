# RFC-008 — Testing / Rollout / Release

Status：**Proposed Architecture**。Current coverage：[AUDIT](AUDIT.md)、[BASELINE](BASELINE.md)、[test index](evidence/test-index.json)。完整cases：[TEST-MATRIX](TEST-MATRIX.md)（修訂後62cases）。Open Decision：所有OD在其依賴階段簽核；Future Extension不塞入本輪gate。

## Characterization Baseline

既有273tests在Node22+Chromium+PDF+SymPy下全部執行，詳細實測命令/時間/失敗修正見BASELINE。Phase0只增加`tests/uva-characterization.test.js`兩cases：axes改range時frameobject重投影而normalizedink不變；storage序列化回復richmetadata、opacity0emptylockedlayer、gestures、deletedobjects。前者揭露目前Mark沒有worldanchor；後者保護抽離時不可丟資料。不能從它們推論SVG/visual2import完整性。

source-stringtests（如部分unified-canvas）保留但不足以證明多實例runtime。rendergoldens檢查primitives/include/hashes先於像素；property固定seed與誤差；durability以processkill/restart而非只mockPromise；CAS用真SymPy加可控delayservice測race；不降低現有標準、不把新feature未實作case加成default必敗tests。

## Test Execution / Release Gates

每PR需記sourceSHA、Node/Python/Sharp/browser版本、command、exitcode、pass/fail/skip、trace/logartifact。不可把`skip:noBrowser`當pass。CI docs-only當前不跑main Nodejobs，所以本次手動執行基線與新增tests。後續新增testcode要觸發m0workflow；perfcheck應固定runner，不能把sharedcloudrandomlatency硬塞一般unitjob。

Generalcommands仍為`npm test`、`npm run docs:check`、`npm run release:check`、Pythonunittest、browserfiles；每改publictool需docs/TOOLS/updateURI/compatibility docs/releasecheck，不在RFC中把futuretools冒充註冊。Python3.12本次pass不等於CI3.13重跑，Phase7另記productionimage Node22/Python3.13+Compose amd64/arm64。

Release候選必須附 `format support table`（read/write/adapter/lossy/export only）、counts/hashverifiedmigrationreport、sidewrite/rollback實錄、modulev1packagefixtures、legacyURIresponses、真Host驗收。任何未知schema/invalidrefs不可silentdrop，Migration「verified」只能在原始與新domain完整對照後成立。approvalrecord有scope與notapproved，不把agent設計推薦當humanapproval。

1. typed IDs與samebyte/newdoc identities；graph無PNG、無paneldoc可reopen。
2. richMarks、layerorder/lock/opacity0、evidence/rejections、gestures/intent完整；noautomaticflatten。
3. image/graph共用toolbar/geometry/commands/render；eraser/resize/committedundo逐casepass。

5. same-doc2vp/multipleGraph、camera/tool/selection無污染，asyncstale結果不mount。
6. CASusereditconflict、stale/removed/unavailable分開、partialrefreshreport。
7. v1API/ABI/manifests/packagegrants/URIs保留，crossdocauth與egress不擴權。
8. stagedcommitfaultinjection、samekeyhashreplay、ENOSPC、backuprestore與newdata回退演練。
9. perfrawsamples與核准budgets，無渲染quality/limits退化。
10. 真ChatGPTWeb/Mobile逐平台結果；FakeHost另列，未知留openblocker。
