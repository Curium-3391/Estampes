# ADR-006 — Cross-document References

Status：**Proposed recommendation；尚未批准**。Decision不代表正式實作或humanapproval。Current Implementation以本頁Evidence與[AUDIT](../AUDIT.md)為準。

## Context

o IDs local；CAS links僅canvas/object；workspace link shareset、copyfork；evidence也有image refs。

Evidence（CURRENT，baseline 7fb9b73442401fc32a7034888deaf49303e582a6）：`workspace.js copySet/planTransfer / builtin-modules/cas/index.js after / surface/refresh.js refreshLinks`；精確函數位置與sourcehash見[source index](../evidence/source-index.json)。

## Options Considered

A rawID/globallookup；B typedfullrefs+bindingresolver；C mutableScene共享。

## Decision

推薦B：Ref(documentId,sceneId,kind,id)，binding表顯式live/snapshot/status；owner不分享、readresolve驗scope。

## Rationale

copy/import可two-passremap；unavailable/removed/conflict可分；security可限定traversal。

## Consequences

需incomingrefindex、cyclelimit；Move不知closure則block；CASusereditpauses，copydefaultdetach。 Lifecycle、ordering、async/retry與compatibility依[RFC contract](../RFC-006.md)，不從一般架構直覺補規格。

## Rejected Alternatives

A localo2重名會誤連；C ownership/locking/undo無單一authority。
