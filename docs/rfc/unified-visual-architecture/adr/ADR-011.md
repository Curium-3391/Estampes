# ADR-011 — Embedded Document Ownership / Snapshot

Status：PROPOSED recommendation；尚未 Human Approved。補充 ADR-003 / ADR-004 / ADR-006，保留原核心架構；只取代其在本finding的缺漏／衝突規則，不撤銷原singleowner/dualmodel/compat方向。

## Context

Phase0只有embed概念與matrix，缺canonicaltypedobject、bindinglifecycle、derivedcacheevents與cloneownership。 Current實作證據固定7fb9b73；本輪只docs，詳REVIEW-REMEDIATION。

## Options Considered

A parent持childscene副本；B typedembedreference＋child單authority、snapshotclone獨立doc；C embedraster。

## Decision

推薦B；embedded-documentobject+canonicalbinding、defaultparentedit、explicitchildviewport、dependencyvector通知；cycleatomic驗；nestedsnapshotV1明確拒。

## Rationale

維持editablechild與既有Graph引擎；不產第二authority；auth/copy/import/CAS可按typedref驗。

## Consequences

新增trustedobjecttype需PR-6D；snapshot產新doc並保history；child不可讀時placeholder不洩metadata。 正式schema/operations/state/recovery細節見[contract](../EMBED-CONTRACT.md)。

## Rejected Alternatives

A雙可變副本不一致；C違反editable需求；從hit猜edit target不安全。

Tests：UVA-51–54 / UVA-61；Owning PRs：PR-6D / PR-6B / PR-6C；人類審查：OD-04 / OD-06。狀態SPECIFICATION COMPLETE不等於Approved；沒有實作或遷移。原ADR對應段落已加supplement連結。
