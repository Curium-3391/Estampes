# ADR-010 — Internal Generation GC / Journal Durability

Status：PROPOSED recommendation；尚未 Human Approved。補充 ADR-007，保留原核心架構；只取代其在本finding的缺漏／衝突規則，不撤銷原singleowner/dualmodel/compat方向。

## Context

全量immutablegeneration無保留界線，無法以cleanup一句避免磁碟爆量；durableACK與retry需一起保存。 Current實作證據固定7fb9b73；本輪只docs，詳REVIEW-REMEDIATION。

## Options Considered

A永久保留每個fullgeneration；B GC直接按年齡刪oldfiles；C rootedGC+losslesshistory/ledgercompaction。

## Decision

推薦C；current/recovery/pins/checkpoints/historyroot保護；7天fullACK＋永久compacttombstone；分頁root與quotareserve；fsyncbarrier後才ACK。

## Rationale

回收可重建內部副本不刪使用者內容；防忘記request造成重複效果；符合singlewriterfsstack。

## Consequences

logicalhistory真實成長仍存在，quota不足必backpressure；需要maintenancePR與filesystem驗收；unsupportedFS拒durablewrite。 正式schema/operations/state/recovery細節見[contract](../STORAGE-LIFECYCLE.md)。

## Rejected Alternatives

A N*S成長；B可能刪activepin、ACKledger或唯一historicalcontent；不引入分散式GC。
