# ADR-007 — Persistence Migration Strategy

Status：**Proposed recommendation；尚未批准**。Decision不代表正式實作或humanapproval。Current Implementation以本頁Evidence與[AUDIT](../AUDIT.md)為準。

## Context

saveCanvas逐fileatomic且catchlog；surface/notebook各自atomic；router.after failure只audit；沒有跨storecommit。

Evidence（CURRENT，baseline 7fb9b73442401fc32a7034888deaf49303e582a6）：`storage.js saveCanvas/atomicWrite / cas/notebooks.js mutate / modules/router.js runtime.after`；精確函數位置與sourcehash見[source index](../evidence/source-index.json)。

## Options Considered

A SQLite全面遷移；B mutablefiles+compensation；C immutablegenerations+intentjournal+atomicmanifestpointer。

## Decision

推薦C：singlewriter/OCC、stagedfsync、唯一pointercommitpoint、readfixedgeneration；migrationcopy-on-write保originalraw。

## Rationale

符合現有fs stack與單owner；可測kill恢復；durableACK不依best-effortprojection。

## Consequences

必須新readers都走manifest；NFS/多writer不支援；新寫入後rollback需v2archive與backupvolume。 Lifecycle、ordering、async/retry與compatibility依[RFC contract](../RFC-006.md)，不從一般架構直覺補規格。

## Rejected Alternatives

A可行但加DB/雙storage過渡；B無法避免reader見半套scene/notebooklink。

## Validation / Approval

必須通過 UVA-24/31/32/33（[case definitions](../TEST-MATRIX.md)），並完成[Open Decision OD-01](../OPEN-DECISIONS.md)簽核。Implementation Agent不得自行把推薦視為APPROVED。未列能力為Future Extension，不擴大此Decision；規格矛盾先更新ADR再進相依PR。

## Phase 0.1 Supplement

stagedcommit不變；新增V1必要retention/GC/compaction/capacity、boundedroot、durablefsyncbarrier；使用者historypurge仍排除。 詳[ADR-010](ADR-010.md)；推薦待人類批准，非實作變更。
