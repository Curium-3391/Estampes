# ADR-009 — Annotation Authorship / Unified User Editing

Status：PROPOSED recommendation；尚未 Human Approved。補充 ADR-002 / ADR-004 / ADR-005，保留原核心架構；只取代其在本finding的缺漏／衝突規則，不撤銷原singleowner/dualmodel/compat方向。

## Context

Phase0 author只含user/assistant，卻授權moduleannotation，且only-ownuserpolicy限制雙向協作。 Current實作證據固定7fb9b73；本輪只docs，詳REVIEW-REMEDIATION。

## Options Considered

A只擴authorenum；B作者/actor/owner/grants分開＋Unifieduserediting；C V1禁moduleannotation。

## Decision

推薦B；module author明確、signer/lineage owner與currentgrant共同驗；Unifieduser可編輯未鎖AI/moduleink，legacytool不擴權。

## Rationale

保原createdBy/claim/evidence歷史，精確stale/Undo/userguard防覆寫；接近既有sceneops的trustedsource模式。

## Consequences

需新ownerlineage與typedprovenance、contextverification、useractionsession；新產品政策仍需maintainer確認，不能由Agent批准。 正式schema/operations/state/recovery細節見[contract](../ANNOTATION-POLICY.md)。

## Rejected Alternatives

A仍混owner與作者；C與capability目標衝突；把useredit改author=user會丟原來源。

## Validation / Approval

Tests：UVA-41–45；Owning PRs：PR-1A / PR-2A / PR-2B / PR-4B / PR-5A；人類審查：OD-02 / OD-05。狀態SPECIFICATION COMPLETE不等於Approved；沒有實作或遷移。原ADR對應段落已加supplement連結。
