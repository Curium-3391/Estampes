# ADR-012 — Legacy Authority Cutover / Old Binary Fencing

Status：PROPOSED recommendation；尚未 Human Approved。補充 ADR-001 / ADR-007 / ADR-008，保留原核心架構；只取代其在本finding的缺漏／衝突規則，不撤銷原singleowner/dualmodel/compat方向。

## Context

Shadow/sidewrite/flags原文未逐態凍結writer；原binary不認新lock/marker，不能聲稱自動拒寫。 Current實作證據固定7fb9b73；本輪只docs，詳REVIEW-REMEDIATION。

## Options Considered

A flags決定雙storewrite；B atomicauthoritymanifest+mediatedwriter+OS/launcherfence；C 強制全量inplaceconversion。

## Decision

推薦B；A0–A7唯一authorityepoch；cutover同commit發布doc/alias/seal/ledger；legacyprojection獨立tree；oldbinary只能readonlysnapshot或新downgradevolume。

## Rationale

避免previewrace、projectionfallback與oldbinary寫壞unifieddata；rollback有新寫入先保全。

## Consequences

不具fence環境拒writablecutover；需deploymentlauncher/mountnamespace或DockerROmount；不假裝修改原oldcode。 正式schema/operations/state/recovery細節見[contract](../AUTHORITY-CUTOVER.md)。

## Rejected Alternatives

A flags不提供transaction safety；C違反原資料不改與分階段約束；marker單獨無效。

Tests：UVA-56–58 / UVA-62；Owning PRs：PR-1B / PR-6B / PR-7A；人類審查：OD-01 / OD-06。狀態SPECIFICATION COMPLETE不等於Approved；沒有實作或遷移。原ADR對應段落已加supplement連結。
