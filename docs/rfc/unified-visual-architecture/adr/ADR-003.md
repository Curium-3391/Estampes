# ADR-003 — Viewport State Ownership

Status：**Proposed recommendation；尚未批准**。Decision不代表正式實作或humanapproval。Current Implementation以本頁Evidence與[AUDIT](../AUDIT.md)為準。

## Context

visual-surface的cam/mode/selected/past是singleton；workbench只搬同一#panel-canvas；calculator已按panel分state。

Evidence（CURRENT，baseline 7fb9b73442401fc32a7034888deaf49303e582a6）：`public/visual-surface.html setCam/applyInput / public/workbench.js canvasPanel/renderWB`；精確函數位置與sourcehash見[source index](../evidence/source-index.json)。

## Options Considered

A 每Panel複製全域script；B DocumentStore共享內容、controller per runtime viewport；C camera存Document同步。

## Decision

推薦B：persistentViewport slot與(widgetInstanceId,viewportId,bindingGeneration)runtime分開；camera/selection/tool獨立。

## Rationale

同doc兩視圖同步內容又可獨立互動；latecallback可驗epoch；panelclose不改doc。

## Consequences

需要factory/dispose/subscriptions；camera僅explicitpreset保存，不強推到其他widget。 Lifecycle、ordering、async/retry與compatibility依[RFC contract](../RFC-004.md)，不從一般架構直覺補規格。

## Rejected Alternatives

A全域DOM/keyboard/request會碰撞；C違反viewport獨立且pan形成內容revision噪音。

## Validation / Approval

必須通過 UVA-13/14/16/17/18/35（[case definitions](../TEST-MATRIX.md)），並完成[Open Decision OD-04](../OPEN-DECISIONS.md)簽核。Implementation Agent不得自行把推薦視為APPROVED。未列能力為Future Extension，不擴大此Decision；規格矛盾先更新ADR再進相依PR。

## Phase 0.1 Supplement

viewport獨立不變，livechildcommit以dependencytoken更新parentviewport，parentrevision不偽增；drawingdefaultparent。 詳[ADR-011](ADR-011.md)；推薦待人類批准，非實作變更。
