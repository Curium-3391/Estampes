# ADR-008 — Compatibility Adapter Strategy

Status：**Proposed recommendation；尚未批准**。Decision不代表正式實作或humanapproval。Current Implementation以本頁Evidence與[AUDIT](../AUDIT.md)為準。

## Context

既有tools/URIs/visual1/2/bundle1/workspace1/module1/ABI1有使用者；新Graph不能用oldimageformat無損表示。

Evidence（CURRENT，baseline 7fb9b73442401fc32a7034888deaf49303e582a6）：`server.js LEGACY_VISUAL_URIS / protocol.js READABLE_PROTOCOLS / bundle.js BUNDLE_FORMAT / modules/manifest.js`；精確函數位置與sourcehash見[source index](../evidence/source-index.json)。

## Options Considered

A 強制全面升級；B 保legacyroutes與explicitv2；C 自動raster/fakeimgdowngrade。

## Decision

推薦B：dualread、v2opt-inwrite；legacyimageadapter保語意、newdoc新kind；不可表示時typederror/lossreport不flatten。

## Rationale

保護savedconversation/packagegrants與editabledata；migrationreview可逐phase完成。

## Consequences

維護版本矩陣與goldenfixtures；至少兩minor推薦保legacyreader，實際期限待maintainer；舊binary僅backupvolume。 Lifecycle、ordering、async/retry與compatibility依[RFC contract](../RFC-005.md)，不從一般架構直覺補規格。

## Rejected Alternatives

A違反相容約束；C破壞docidentity/anchor/evidence與可重編。

## Validation / Approval

必須通過 UVA-23/24/25/27/28/35（[case definitions](../TEST-MATRIX.md)），並完成[Open Decision OD-06](../OPEN-DECISIONS.md)簽核。Implementation Agent不得自行把推薦視為APPROVED。未列能力為Future Extension，不擴大此Decision；規格矛盾先更新ADR再進相依PR。
