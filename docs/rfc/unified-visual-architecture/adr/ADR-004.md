# ADR-004 — Coordinate Anchoring

Status：**Proposed recommendation；尚未批准**。Decision不代表正式實作或humanapproval。Current Implementation以本頁Evidence與[AUDIT](../AUDIT.md)為準。

## Context

frameOf已有world↔normalized，但user marks只有image-normalized；screen位置、workspaceplacement不同。

Evidence（CURRENT，baseline 7fb9b73442401fc32a7034888deaf49303e582a6）：`scene/objects.js frameOf / image/transform.js mapMark / visual-surface.html fromPointer`；精確函數位置與sourcehash見[source index](../evidence/source-index.json)。

## Options Considered

A Graphink默認world；B 默認document、explicitworld/object；C 由重疊/nearestpoint猜。

## Decision

推薦B：每anchor有space/ref/units，function-x固定x；invalid retainlastpose；screenfixed為ViewportOverlay。

## Rationale

符合既有marks不隨range移動；多axes無歧義；function刪除不丟annotation。

## Consequences

需invalidUI與reanchor/detachpreview；world手繪必明確選frame；外部refs不自動配對。 Lifecycle、ordering、async/retry與compatibility依[RFC contract](../RFC-003.md)，不從一般架構直覺補規格。

## Rejected Alternatives

A可合理但改變預設圖上圈選位置；C不可驗證意圖且跨匯入不穩定。

## Validation / Approval

必須通過 UVA-08/09/12/22（[case definitions](../TEST-MATRIX.md)），並完成[Open Decision OD-02](../OPEN-DECISIONS.md)簽核。Implementation Agent不得自行把推薦視為APPROVED。未列能力為Future Extension，不擴大此Decision；規格矛盾先更新ADR再進相依PR。
