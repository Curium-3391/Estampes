# ADR-005 — Module Target API

Status：**Proposed recommendation；尚未批准**。Decision不代表正式實作或humanapproval。Current Implementation以本頁Evidence與[AUDIT](../AUDIT.md)為準。

## Context

module/1 stricttargetenum與ctx.canvas/imageId；WASM/1固定request；canvas.read/write與workspace.write已有grant。

Evidence（CURRENT，baseline 7fb9b73442401fc32a7034888deaf49303e582a6）：`modules/manifest.js validateManifest / router.js createRouter/canvasContext / runtimes/wasm.js`；精確函數位置與sourcehash見[source index](../evidence/source-index.json)。

## Options Considered

A 改所有manifest/1targetenum；B module/2+explicitdocscene+v1imageadapter；C 所有cap新增專用MCPtool。

## Decision

推薦B：target none/document/document-or-new；新permission/ABI明確版本；v1bytes/signatures與image語意保留。

## Rationale

避免改v1schema卻宣稱相容；不向thirdparty捏造imageId；維持固定execute_moduleentry。

## Consequences

要支援graphdoc需moduleupgrade+重新grant；v1canvas-or-new仍建legacyPNG。 Lifecycle、ordering、async/retry與compatibility依[RFC contract](../RFC-005.md)，不從一般架構直覺補規格。

## Rejected Alternatives

A破壞strictreader與signedmanifest；C動態toollist與target/permission分散。

## Validation / Approval

必須通過 UVA-27/28/29/30（[case definitions](../TEST-MATRIX.md)），並完成[Open Decision OD-06](../OPEN-DECISIONS.md)簽核。Implementation Agent不得自行把推薦視為APPROVED。未列能力為Future Extension，不擴大此Decision；規格矛盾先更新ADR再進相依PR。

## Phase 0.1 Supplement

modulev2不變；annotation.write.owned需publisher/lineage/currenteffectivegrants，moduleId/manifest聲稱不足，import不授權。 詳[ADR-009](ADR-009.md)；推薦待人類批准，非實作變更。
