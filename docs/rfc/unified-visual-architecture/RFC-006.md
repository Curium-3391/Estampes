# RFC-006 — Workspace / Storage / Migration

Status：**Proposed Architecture**；本次沒有執行遷移。Current Implementation：storage/bundle/workspace/bundle-extras 的source與限制見 [AUDIT](AUDIT.md)。Open Decision：OD-01/06（cutover/舊版可表達範圍）；Future Extension：multi-process writer、跨server live references、使用者Document/history purge；安全Internal GC/compaction已屬V1必要規格，見STORAGE-LIFECYCLE。

## Persistence Schema / File Responsibilities

既有`images/<hash>/source,meta.json,canvas.json,sets/*.json,derived.json`不改原位；`documents/<sha>`目前為PDF bytes，**新store用 `visual-documents/`**避免collision。Proposed：

```text
visual-documents/<doc-uuid>/generations/<revision>-<hash>.json
visual-scenes/                    # 不獨立寫入；V1 scenes inline於doc generation
visual-assets/<full-sha>/meta.json # bytes可引用既有immutable images source，hash核驗
visual-migrations/<migrationId>/manifest.json
visual-migrations/<migrationId>/raw/<safe-index>.json
visual-migrations/<migrationId>/report.json
visual-registry/generations/<generation>.json
visual-registry/CURRENT.json      # single committed generation pointer
visual-registry/pages/<hash>.json # bounded copy-on-write index pages
visual-history/<entity>/packs/<hash>.json # lossless checkpoint/delta packs
visual-ledger/packs/<hash>.json    # full ACK window + permanent compact tombstones
gc-quarantine/<gcId>/             # internal unreachable files only
visual-transactions/<txId>/intent.json
visual-transactions/<txId>/prepared.json
visual-transactions/<txId>/outcome.json
visual-notebooks/<id>/generations/<revision>-<hash>.json
visual-surfaces/<id>/generations/<revision>-<hash>.json
visual-workspaces/<id>/generations/<revision>-<hash>.json
```

`visual-scenes/`只為保留命名界線的文字示意，V1不建立空資料夾、不分拆scene原子性。generation manifest列doc/nb/surface/workspace refs與hash、legacy alias registry、transaction id及idempotency results。新readers先抓CURRENT generation再解refs，整個read固定generation；不把不相同gen的stores當同一snapshot。rootmanifest<=64KiB、indexpage<=4MiB，從V1即採hash分桶copy-on-writeindex；不得每次複製全entity/ledgermanifest。詳[STORAGE-LIFECYCLE](STORAGE-LIFECYCLE.md)。memory-only同一coordinator在memory publish generation，不聲稱durable或restart可恢復。

## Non-destructive Migration Algorithm

1. **Discover**：讀source snapshot，列safe relativepaths、bytes/fullSHA、schema、count、available refs與unsupported fields；限定本server owner選擇的範圍，不掃任意filesystem。寫migrationId、sourceRevisionVector、sourceHashes、versionedplan；不寫原source。
2. **Allocate**：為每distinctsetKey一個doc/sc ID；以registry reuse既有同來源mapping；新mapping UUID在plan持久化，retry不重新分配。object/layer/mark localIDs保留，duplicate同namespace→blocking issue；不同doc同ID合法。fullasset hash相同才共享，短img collision阻擋。所有mapping `(sourceStoreId,schema,legacyKey,kind,localId)→newRef`，不使用名稱或位置推測。
3. **Convert**：一對一field map；每個source leaf field須classified mapped/archived/explicitly-excluded；未分類即plan invalid。unknownschema整份隔離，只可read-only preview；unknownentity raw存quarantine與占位，預設commit blocked，由user選保留隔離可commit但report非完整editable success。無驗證欄位預設unverified；不做trust promotion。
4. **Resolve**：同batch internal refs先allocate再rewrite；external local refs只查legacy registry，找不到存unresolved；不跟URL/同名猜。gesture groups全members mapping，CAS依RFC005，evidence ref記原asset及frame。原review保留，新增migration verification為另一欄。
5. **Verify dry-run**：同manifest snapshot算assets/scenes/objects/annotations/layers/relations/gestureDecision counts、geometry/raw-evidence hashes、reference closure、每layer content唯一、owner唯一、render包含項與pixelbounds；比較legacy source domain而非只marks count。產before/afterpreview（renderer profile legacy）與warnings/blockers，sign planHash。
6. **Commit**：明確來源與target rev+source hash未變才coordinator publish；changed→STALE_PLAN，必須重新preview。default copy-on-write不動source，不自動extractGraph。migrationledger紀錄planHash/tx/result mapping，exact request replay回原result，同key異payload拒絕。
7. **Report / Reopen**：server重新載入new committedgeneration，不以in-memory draft作驗證；對全部semantic hashes/counts/ref resolution重新check。報 `verified`限檢核通過且無unreportedloss；quarantine明列 `editableComplete:false`。原始資料及migration raw繼續保留。
8. **Rollback**：按[AUTHORITY-CUTOVER](AUTHORITY-CUTOVER.md) A7 rollbackcontract，無postcutovereffects且seal/ledger證據完整才可transition回legacy；已有newwrites必凍結並保存v2archive/完整volume，只可另建legacy可表示資料的新volume，不作原位pointer回退丟data。舊binary只對備份volume啟動，不能共用active newstore寫入。

## Graph Separation Preview / Mapping

獨立Graph creation不等於自動拆舊canvas。工具proposed `plan_graph_separation` 接受 `{sourceRef, axesIds, selectedAnnotationIds, selectedObjectIds, mode, annotationAnchorChoices}`，必回source rev/hash、selected dependency closure、ambiguous items、proposed layer/object/ref maps、CAS impact、before/after editable preview、counts與planId。commit需planId+hash+source/target revisions，不能直接根據bbox把marks帶走。

- axes-2d為明確root；function-plot/space:frame shape按props.frame構成自動**候選**closure。其他axes、canvas-space shape、LLM/user Marks、image objects都不由重疊決定owner。sharedLayer不能全搬，plan列splitLayer與保留項。
- 預設推薦copy：selected graph objects保留數學range/domain；採 `preserve-document-layout` mapping（source extent/axes.region照存）使選中image-normalized marks轉documentdu後與圖同位置。若選「放大至新圖」使用明確affine G（source region→target region），展示矩陣；world shapes保留worldcoords僅axesregion改；doc/canvas marks套G；rect非axisaligned保留polygon顯示。
- User/LLM Marks只有explicit selected IDs才包含；每筆指定document/world/object anchor；缺選擇預設preserve-document-layout+document anchor並在preview列明，不猜world。Frame-space graph objects有確定frame，但Mark沒有，不能從鄰近關係補出。crossframe mark群拆選時保留unresolved group decision或整群copy，由preview阻擋丟member。
- layers複製name/author/module/opacity/lock/visible，split映射記derivedFrom，不取消locked來搬內容；Move涉及locked object/mark回LOCKED，須先explicitunlock。evidence永遠指原來源asset與region；幾何移動不把old evidence改稱新圖獨立驗證。provenance完整＋migration event；rejection history與refs一併map。
- source doc + target doc + workspace ref + notebook CAS binding改動在同coordinator transaction。Move需更新所有已知local incomingrefs，未授權/無法完整列出→block Move，Copy仍可行。跨docframe reference不保留，closure不完整→BLOCKED_DEPENDENCY。CAS target mapping列出每個link，Copy預設detach-live保留historical provenance，user可explicitcopy-live-links並新binding；Move轉target同source cell binding，lastApplied重新驗，不能雙重refresh。

| 操作 | 新資料 / references | 後續修改是否共享 | source行為 |
| --- | --- | --- | --- |
| Move | 原entity轉新owner＋global ref map，來源tombstone/redirect（保留original local identity history） | 新owner唯一，refs redirect；不兩邊mutable | 刪除被選activeentities需授權/OCC，rawbackup不刪 |
| Copy | 新doc/scene/entities deep copy，assets可共享immutable | 不共享content；CAS預設detached | 來源不變 |
| Link | workspace或relation新增typed ref，不改owner | 是，仍同doc/object | 來源不變 |

| Detach | live embed/link複製當前editable child snapshot；anchor detach轉可解析doc geometry | 不再共享，保留derivedFrom | 原來源不刪，linked CAS從target解除 |

## Bundle Format / Import Integrity

`estampes.bundle/2` ZIP：manifest.json（format/minReaderVersion/bundleId/fullfileshashes、schemas/counts）、assets/fullsha bytes、documents/n.json、notebooks/n.json、workspaces/n.json、surfaces/n.json、bindings.json、interactions/n.json、migration-report.json。Scenes/annotations/layers inline完整doc；viewport overlays只explicit inclusion。no secrets/keys/signed URLs/module executable packages/chattranscript；public/scratch scope列manifest，scratch需ownerexplicitinclude，不讓export route繞權限。

檢核順序：zip path safety、entry/total/decompressed limits（先沿用400/400MiB/200MiB上限；如新doc數超限回typed LIMIT不提高）；唯一manifest與檔名；schema supported/minReaderVersion；所有參照檔案都須在files列且sha/size匹配；拒duplicatefile與object IDs；逐entity validate；allocatedref map完整；counts分active/quarantine/tombstone；migrationreport原counts/映射一致；render可重建；coordinator單次publish。新unknownformat回UNSUPPORTED_SCHEMA、不走舊cleanSet忽略；partial import必先preview選擇與lossReport，不能verified:true。

Import所有mutable IDs新namespace（含nb/cell/result/panel/vp/workspace/binding/interaction）；source IDs存provenance mapping。immutableassets按fullhash共用；repeat import同bundleHash+importscope+optionsHash回原importledger結果，`forceCopy`新request explicitly新IDs。ref向bundle外預設unresolved且不自動綁本機同ID；user explicitmatch才能link，須currentrev+auth。Notebook imports全部stale，cell/result historicalrefs remap，newrecompute產新ID。v1 exporter僅可表示image docs與既有data模型，不能自動扁平world anchors/embeds/Graph；提供loss analysis，拒聲稱lossless，選擇legacy image projection須顯式操作且保留newarchive。

## Cross-store Consistency / Recovery

| 方案 | 優點 | 代價 / 決定 |
| --- | --- | --- |
| DB atomic transaction | 強原子，query能力 | 引入SQLite遷移與既有fs雙write，當前需求未證明必要；保留未來選項 |
| 獨立rename後compensation | 小改動 | crash中間state已可見、補償可能失敗，CAS link不可證一致；拒作權威策略 |
| append WAL重播mutable files | 可恢復 | 需read隔離與重播duplicate邏輯，partial files仍難擋舊readers |
| **staged immutable generations + intent journal + atomic manifest pointer** | 單process單owner適合，read generation固定，現有fs stack可增量引入 | 推薦；需要strict fsync、所有新readers同manifest，legacy write route必adapter，舊binary不共寫 |

Transaction FSM：`planned → validating/locked → prepared → committed → materialized`；prepared前可aborted；committed後不可abort，只新compensatingtransaction。流程：排序取得entity locks→OCC+permissions→clone/apply+refs驗→writeintent(request hash/beforegen/after hashes)並fsync→immutablefiles write tmp/fsync/rename、fsync dirs→prepared manifest fsync→globalcommitlock內重check unrelated currentgen並compose registry→atomic CURRENT rename+fsync dir（唯一commitpoint）→publish memory+ACK+event→legacy projection/garbage cleanup。不同documents計算可並行，pointer publish短序列化，不覆蓋另一tx manifests。

Startup先受管writerlease/mountfence；readCURRENT驗closure，不猜latest；依STORAGE-LIFECYCLE的compactcommitindex判intentmembership，不遞迴pin全部祖先；未commitstage按quarantine/retention規則維護，已commit補outcome/events不重apply，ACK遺失由7天完整ledger回覆，過窗永久tombstone拒重apply。committedmanifest壞檔不能把已ack資料悄悄rollback，進recovery並從backup查核。power-loss durability取決local filesystem atomicrename/fsync；NFS/共享volume不支援，health明示。

A4/A5的Legacy projection非authority、best effort可重建，不以現有saveCanvas swallowing error當成功；A4/A5所有legacy writes經adapter，同document OCC/commit；A0–A3依authoritytable，legacy原source仍是唯一authority；read legacyimage response由當前snapshot投影。phase1 shadowread僅比較，尚未cutover不允兩個writers分別當權威。停機、ENOSPC、permissionerror、CASafterfailure、duplicate retry、processkill各stage的UVA-31/32/33為上線門檻。
