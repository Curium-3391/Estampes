# Test Matrix — Proposed Acceptance Specification

Status：**Proposed tests**；只有 [BASELINE](BASELINE.md)列出的既有tests與兩個characterization cases已執行。新功能不存在時本表是spec，不建立必敗CI tests。Current coverage欄區分unit/sourceassertion/MCP/fakebrowser，均不是realhost驗收。Future Extension（CRDT、segment eraser、3D、跨server）不以skip偽裝V1完成。

## Fixture / Automation Conventions

- F-IMG：合成1600×1000白底asset，defaultset含2user+2assistantmarks、1×128-pointstroke、lockedlayer與opacity0layer、evidence/confirmed/rejectedclaim、gesturedecision、pairlink、emptylayer。所有metadata欄位canonicalhash保存。
- F-GRAPH：Graph doc無asset，axes[-10,10]²、sin/tan、framepoint(2,3)、document circle、world circle、function-x anchor x=2，public/scratch各一；至少兩layer。
- F-CAS：nb有definition f(x)=x²、cell derivative、CAS-ownedplot與binding，result/env/target revision固定；backend可控制delay/cancel。
- F-LEGACY：由基線serializeCanvas/visual/2/bundle/1建立fixture，包括fork img#c、baseAsObject、deletedObjectBatches、PDFrecipe、未知object和danglingref；不能只手寫與新schema相同的資料。
- F-HOST：現有startStack實server+Chromium+fakeMCPAppsparent；可注入工具結果重送、lostACK、outoforder、missing_meta、widgetdispose；不得自稱ChatGPT。
- Invariants簡碼：I1 typedidentity/owner；I2 geometryhash不變；I3完整metadata/counts/hash；I4 permission/lock；I5revision/commit/idempotency；I6 viewport隔離；I7evidence不升級。每列均另列該case特定不變條件。
- Automation：U=Nodeunit/property、M=MCPintegration、B=fakebrowser、F=faultprocess/harness、P=benchmark、H=manualrealhost。Priority P0阻擋相依PR，P1阻擋phaseexit。P2只Future，不列本輪必要案例。
- `tests/uva-*.test.js`為**Proposed paths**，PR啟用相依功能時新增。現有tests維持，不能改assertion降標準；sourceassertions可加runtime驗證，但不直接刪除原coverage。Phase欄為最早必須通過階段。
