# Reproduce this phase

Use Node 22 and a clean checkout of this branch. All engine stores are owned disposable fixtures; no active product storage is used. `run.py` accepts an explicit argv without a shell, refuses log overwrite, and records UTC time, exit code, input hashes, configuration and raw-output SHA-256 in runs.jsonl. Run new names when repeating.

1. Verify the exact origin Round 3 commit `31dae29f1cf7d1e8caf6c670124eed7c7ed91e11`, ancestry from `b2f853c5e7473a008552ff70c838de3faff07c20` and `94f3b59f1b5eabe6ce8dabfc33362ddb35a27bc4`, and empty source/tests/scripts/package diff from implementation baseline. baseline-sha256.json records all tracked initial bytes.
2. The red replay used a disposable copy of baseline src/tests/package.json with node_modules linked to this checkout, and copies of the original Round 3 harnesses adapted ONLY from native profile/durable expectations to process-crash/memory. The original repository evidence is never edited.
3. `python3 prepare-replay.py REPOSITORY EMPTY_TEMP_TARGET` creates src/tests/node_modules symlinks and adapted original harness copies for all three historical evidence directories. replay-hashes.json binds original and transformed bytes. Set PR1D_ACCEPT_ROOT to an owned disposable scratch directory for the original partial-write preload (acceptance.sh does this); run explicit `.mjs` entrypoints from that target; log filenames are not test entrypoints.
4. Run `python3 prepare-baseline.py REPOSITORY EMPTY_BASELINE_TARGET` to recreate the exact source/tests/package baseline without switching the checkout. Run `node --test --test-concurrency=1 tests/persistence-state-machine.test.js tests/persistence-filesystem-trust.test.js`, then complete Node serial with CHROME_BIN and CHROMIUM_BIN set to an installed Chromium. Run original independent cases and fault suites separately. Native-positive cases must skip/refuse when approved ext4/XFS is unavailable.
5. `bash qualify.sh NODE22 BASELINE_CODE_ROOT` runs serial 50/100 paired histories, four 8 MiB revisions, a separate auto-maintenance-enabled qualification, then the initial complete suite. Final delivery reruns `node --test --test-concurrency=1` as final-node22-serial after the read-only-backup compatibility followup. The isolated 25 pair was run separately through benchmark.mjs. Baseline code root is an exact source/tests/package copy of 31dae29. Both sides use the same current workload script, fresh JS caches on reopen and a ten-minute workload bound; OS page cache is not dropped. Startup timeout remains 30 seconds.
6. Run environment.py, existing contract validator (22 tests), nine formal examples, Python CAS (17 tests), docs/release/check-consistency.mjs, verify-preservation.py and Git whitespace checks. `seal.py` verifies full-suite source/test hashes, run-log hashes and final report/trust/checker hashes and writes a separate manifest.

The original Round 3 adversarial before-ACK assertion additionally requires old CURRENT after publication. That assertion remains preserved and is expected to fail against conservative no-rollback handling. The normal-discovery regression requires detection, no ACK, fencing, selected CURRENT/committed Ledger preservation and failed restart for corrupt content. The original metadata diagnostic expects stale proof acceptance if collisions occur; retain its exact result separately from the corrected rejection regression. Neither is silently converted into a green acceptance result.

Two initial 50-history workers briefly overlapped; their logs/results remain but are excluded from performance conclusions. Use paired-* for 50/100/8MiB, and baseline-history-25 / candidate-history-25 for 25. tmpfs/overlay observations do not qualify native durable storage, WSL ext4, host flush or power loss.
