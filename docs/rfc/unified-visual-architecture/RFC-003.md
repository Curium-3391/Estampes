# RFC-003 — Coordinates / Rendering / Interaction

Status：**Proposed Architecture**。Current Implementation：`frameOf`, `mapMark`, `getScreenCTM`, `markSvg`, `renderCanvas`, `renderObjects`, `restackLayers` 見 [AUDIT](AUDIT.md)。Open Decision：OD-02/03；Future Extension：segment eraser、非線性frames、implicit/parametric curves。

## Coordinate Spaces / Persistence Rules

所有數值finite IEEE754 double；不在每次pointermove round-trip時改寫canonical座標。矩陣row-major 3×3、column vector；`multiply(B,A)`代表先A後B，沿用image/transform。位置與stroke width分開：CSS pixel hit tolerance不回寫geometry。

| Space | 原點、單位、軸 | Forward / inverse | Persistence、rotation/scale、clip / invalid |
| --- | --- | --- | --- |
| Screen S | browser client左上，CSS px，x右y下；page scroll不混入client | viewport client rect offset與DOM CTM inverse，S→V | 不存device/screen absolute px；getScreenCTM缺失/不可逆停止gesture，不用(0,0)替代 |
| Viewport V | viewer content左上（扣header/padding），CSS px x右y下 | V = Camera × D；D=Camera^-1×V；fit letterbox包含在Camera | camera prefs以doc center+zoom+rotation，不存DOM尺寸；runtime pointer/selection不持久；clip至viewer rect |
| Document D | scene extent左上du，x右y下；無實體PNG要求 | D = diag(W,H,1)×N；Camera含fit scale、zoom、pan、center rotation | canonical scene geometry；image W/H固定校正尺寸，graph1600×1000；改extent是顯式command不因panel resize觸發 |
| Image Normalized N | 校正後image左上，unit 0..1 x右y下 | N=(Dx/W,Dy/H)；原始pixel via EXIF/source→working→normalized matrix；反向沿recipe | legacy geometry原值保留；新寫入image anchors須[0,1]；derived越界不可靜默clamp，回OUT_OF_BOUNDS或explicit crop choice；import保留raw隔離 |
| Mathematical World F | 數學原點(0,0)，unit由axes定義，x右y上；未必可見 | `Nx=rx+(x-xmin)/(xmax-xmin)*(rx2-rx)`；`Ny=ry2-(y-ymin)/(ymax-ymin)*(ry2-ry)`；inverse同frameOf | 保存world points + frameRef，不存投影後geometry；view range只改mapping；domain clip只影響渲染，不刪out-of-range ink |
| Object Local O | shape local左上或function point anchor，明示unit/local transform | D = objectToDocument×O；function anchor D=frameToDocument(x,f(x)) + doc offset | 保存objectRef、anchorKind、params/offset；幾何transform可含rotation/非等比scale；function undefined/target deleted保留invalid+lastResolvedPose |
| Workspace Placement W | workspace左上，wu，x右y下；非Document space | W = Translate(x,y)×Rotate(0/90/180/270)×Scale(width/Dw)×D；inverse計算corner offset沿legacy placement規則 | item placement存workspace；移/縮/旋轉item不改document ink；clip視workspace/item explicit policy；missingdoc顯placeholder不改其他item |

Homography apply先除w；`|w|<1e-12`、nonfinite、矩陣condition>1e12一律NON_INVERTIBLE，不輸出巨量點。正/反轉換可共用`invert` condition guard，但增加typed failure。驗收誤差以coordinate範圍自適應：document round-trip `<= max(1e-8 du, 1e-10*extent)`；world `<= max(1e-8,1e-10*range)`；derived source pixel <=0.5 px（包含existing round與raster sampling，不宣稱pixel exact）；legacy5位normalized round差異記report，禁止反覆重投影累積。若符合condition但不符tolerance，保留原始geometry並報錯。

任意旋轉/透視下rect的4 corners全部轉換；不再是axis aligned時display polygon，canonical rect+anchor不被bbox替代。stroke widths document scale與screen-fixed明確分型；rotation不改文字語義，HUD文字可保持upright。Graph region外world ink標為clipped，失效錨點以warning glyph呈現，LLM read也帶status。

## Anchoring Policy

```ts
type Anchor =
 | {space:'document'}
 | {space:'image-normalized';asset:AssetRef;sourceToDocument:number[]}
 | {space:'world';frameRef:Ref}
 | {space:'object';objectRef:Ref;
     attachment:{kind:'function-x';x:number;offsetDu:{x:number;y:number}} |
                {kind:'local';localToDocument:number[]};
     onMissing:'retain-invalid';lastResolved?:{originDu:number[];localToDocument:number[];
       geometryHash:string;revision:number}};
type ViewportOverlay = {id:string;viewportId:ViewportId;space:'viewport-css';
  geometry:unknown;intentEventIds:string[]};
```

1. 新Graph freehand預設**document space**，工具列顯示「固定於文件」；手繪圈存du points/smooth/closed/style/finding/provenance。axes range改動，圈不移動；不自動判斷圈了哪個函數。Image legacy marks保持image-normalized。
2. 使用者或LLM明確指定world + frameRef才轉world；pointerdown固定anchor policy與frame snapshot；送出時該frame revision不同則CONFLICT保留draft，不在新axes上悄悄重新解讀。world圈隨axes變動投影；zoom/pan只是viewport camera，兩類ink都隨camera顯示。
3. function attachment V1只接受function-plot `function-x`：保存固定x，修改expression後由trusted parser求新y，offsetDu固定；不作nearest-point重新猜測，不自動移x；x不在domain或y非finite → `invalid(reason)`，顯lastResolved虛線+badge，不能當fresh evidence。functions刪除→target-removed，annotation保留可選取/重新錨定/detach。
4. object local anchor geometry為anchor-relative；Frame/target ID不存在時retain-invalid（無lastResolved則列在失效標註列表，不畫到原點）；換frame、reattach、convert space都需explicit command+preview。references不得靠o2/string label或空間重疊回復。
5. Screen-fixed標註明確定為**ViewportOverlay**：屬特定viewport的持久Surface preference，CSS px相對viewer左上；resize若越界保留坐標但顯可回復提示，不改Document。預設不隨doc export、不參與document revision、不送給LLM作doc annotation；可explicit「轉成文件標註」以當時inverse camera寫document。overlay export另有`includeViewportOverlays`與viewport size metadata。不得把它當各viewport共享mark。
6. Graph嵌入Image Document採[EMBED-CONTRACT](EMBED-CONTRACT.md)正式schema：clipRegion為child-document rect、affine localToDocument、canonicalbinding。child world→childD→parentD→viewport；drawing預設parent，explicitenter-edit才指child。snapshot是獨立可編輯clone Document，無child副本權威或raster中轉。
7. copy/import重建document/scene/ref maps；純doc/world座標不因rename重投影。搬移workspace item只placement改動。刪除axes不得cascade刪annotations；object可沿legacy scene-ops cascade，但annotation refs轉invalid。detach anchor使用lastResolved converting to doc coords，無可解析姿態則回UNRESOLVED_ANCHOR。

Object-anchor的Annotation.geometry使用local du offsets，anchor origin為target localtransform origin或function(x,f(x))+attachment.offsetDu；每geometry點只加一次origin，不再把geometry當absolute D。local attachment矩陣映射local→document；function attachment只translation，不因曲線斜率旋轉ink。lastResolved保存完整origin/transform與resolved geometry hash，不能只靠單個點回復polygon；失效仍有原geometry與matrix可稽核。

## Unified Render Contract

```ts
interface RenderRequest {
  documentId:DocumentId; sceneId:SceneId; expectedRevision:number;
  audience:'user'|'model'|'export'; renderProfile:'legacy-canvas/1'|'unified/1';
  hiddenLayerIds:string[]; regionDu?:number[];
  target:{kind:'browser'|'png'|'webp'|'svg';width:number;height:number;dpr:number};
  includeLabels:boolean; includeViewportOverlays?:boolean;
}
interface RenderPlan {
  schema:'estampes.render-plan/1'; documentRevision:number;sceneRevision:number;
  rendererVersion:string; contentHash:string; mapping:number[];
  groups:{layerId:string;opacity:number;clip?:unknown;
    primitives:TrustedPrimitive[];hitRegions:HitRegion[]}[];
  included:{objects:string[];annotations:string[];assets:string[]};
  excluded:{scratch:string[];hiddenLayers:string[]}; diagnostics:unknown[];
}
```

RenderPlan由pure trusted code接受immutable snapshot+validated request生成；scene renderer產objects，annotation adapter保留domain語意再產primitives，LayerComposer共用。禁止在Browser拿raw SVG/HTML。vector primitives僅path/circle/text/image allowlist，path是有限points，text經escape/textContent，raster只可來authorized asset（或legacy validated PNG），不允外部href。frame clip與viewport crop分開；missingasset placeholder+diagnostic，不捏造白底當original。

Composition依序：scene background；layers bottom→top；layer.content順序；每primitive自身alpha×layer.opacity；document visible=false不渲染，viewport hidden override再排除；scratch只有authorized model preview明確include可看，public/export預設排除，不能因module被停用而刪已存public objects。legacy migration layer.content先objects（原Map插入序）再assistant marks再user marks，符合restackLayers；empty/unlayered retain。移layer不改anchor。

`legacy-canvas/1`保留existing筆觸尺寸、送出user ink .55等；`unified/1`canonical geometry alpha不因已傳聊天改變，只有authoring decoration淡化pending/context。這是OD-03的可見變更，經批准才對新doc啟用；legacy不暗中換樣式。server/model/export同一profile、snapshot與hidden overrides時，included refs、layer order、clip、alpha、stroke width必須一致；selection/handles/hover、HUD、pending草稿列為presentation overlay，不在server default composite。LLM可要求指定viewport read snapshot（帶camera/crop/hiddenIDs），不能只讀source_image聲稱看過Graph。

Stroke width：legacy width units維持width/1000比例；unified canonical width用du，Camera×DPR生成raster，zoom時ink隨document縮放；label/hit handles可screen px，但明列decoration。圖形circle遇非等比transform產ellipse/path，不直接用x半徑。DPR只控制backingstore，不改CSS coords/geometry；maxSide既有64..4096保留server限制。

Render caching key為documentId+sceneId+documentRevision+rendererVersion+profile+authorized audience+layer mask+region+output size/DPR+asset hashes+embedded dependency revision vector。immutable render plan可多viewport共享，camera projection與DOM各自持有；scene rev/count不足以代表layer/mark變更。content更新使相關cache失效；stale asynchronous outputs只有完全匹配request epoch與binding才可mount。大型image decoded bytes受cache budget，minimized viewer暫停渲染且不取消doc訂閱。

Export SVG携完整document archive reference/metadata且標明schema；editable `.estampes`才為完整archive。raster export需explicit format，永遠不能取代document canonical store。server/browser raster差異：primitives/映射/refs須exact，geometry邊界誤差<=0.5 output px；字體抗鋸齒可mask，不能把整個曲線mask掉；fixtures用相同font assets與DPR。UVA-10/11/34驗收。

## Hit Testing / Pointer Arbitration

Hit regions源於RenderPlan；先反投影pointer→scene，再依reverse paint order查geometry。hit tolerance 6 CSS px（user preference可調）轉為du，不能以bbox替代細stroke distance；hidden/clip外/scratch不得命中，locked可選取inspect不可修改。group選擇不合併geometry。selection discriminated Ref，resize handles只對可編輯domain啟用，legacy API保既有移動限制；Unified user可完整編輯未鎖AI/module Annotation，依ANNOTATION-POLICY。

State machine per viewport：`idle → drawing|selecting|moving|resizing|panning|pinching → idle`；每pointer只有一owner。title grip/resize edge由Surface先capture且stop propagation；viewer content由ViewportController；不可document-wide共享pointers Map。

- pen primary + tool draw→drawing；touch單指依tool設定；第二touch→cancel draft stroke並進pinching，所有手指離開前gestureLock，不產落筆。pen drawing時忽略touch palm，explicit兩指gesture需結束pen draft後開始。
- space/middle/pan tool優先panning；select hit+editable→moving，handle→resizing；tool change、pointercancel、lostcapture、blur、panel resize/orientation/unmount都取消未提交gesture並回復before draft。抬筆才提交一個command。
- Eraser V1為whole-mark delete，按reverse order選中可刪annotation；locked/無權限跳過並提示，不刪raster pixels、不切斷stroke。多筆擦除一個有界command，保留undo。
- resize panel只重算Camera fit，保持doc center與zoom；手勢中resize先cancel，不把old DOM coords套new transform。函數range編輯是內容command，camera zoom是view operation，UI分開顯示。
- async preview capture `{documentId,sceneId,viewportId,bindingGeneration,requestSeq,revision}`；每項吻合才render。UVA-13/16/17/18涵蓋完整cancel與late result。
