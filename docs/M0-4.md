# Estampes M0.4 — Generic Visual Surface

## Why this version

M0.3.2 verified one bidirectional number-line interaction inside ChatGPT. M0.4 separates the **visual surface** from the **annotation layer** so the same coordinate and drawing tools work on multiple kinds of content.

This is **not** yet an arbitrary-image import plugin. It uses small, self-contained SVG test scenes, avoiding image permissions, CORS, CSP and remote source availability until we validate the generic interaction.

## New tools

| Tool | Visibility | Role |
| --- | --- | --- |
| `present_visual` | Model + app | Display the embedded visual surface and optional assistant annotations |
| `validate_visual_annotations` | App only | Validate the user's drawn annotations with the MCP server |

The private tool **does not** advertise a widget resource. Only `present_visual` points at `ui://estampes/visual-surface-v040.html`.

The prior `show_number_line` flow is retained unchanged for regression tests.

### Sample tool request

```json
{
  "scene": "landscape",
  "annotations": [
    {"id":"ai-1","type":"point","x":0.794,"y":0.203,"label":"Sun"},
    {"id":"ai-2","type":"rect","x":0.105,"y":0.425,"x2":0.395,"y2":0.91,"label":"House"}
  ]
}
```

Three built-in test scenes are available: `landscape` (house, tree, mountains, sun), `shapes` (circle, square, triangle), and `formula` (E = mc²). The model should not assume that an annotation is accurate unless the location was grounded to the source image.

## UI interactions

1. Choose **點選**, **框選**, or **箭頭**.
2. Click for a point, or drag for a rectangle or arrow.
3. Several marks can be left on the same canvas (up to 30).
4. Undo or clear user marks without modifying original content or AI marks.
5. Click **把標註傳給 GPT**. The widget first validates coordinates through the app-only tool, then separately submits a user message to the chat host. Failure of tool validation does not block the message attempt.

The picture uses a 640×360 SVG viewBox, and interactions are converted through `getScreenCTM().inverse()` into normalized 0–1 coordinates from the source's top-left. This avoids misalignment under responsive resizing, provided the host renders the same SVG viewBox.

User annotation examples:

```json
[
  {"id":"user-1","type":"point","x":0.25,"y":0.5,"label":"YOU 1"},
  {"id":"user-2","type":"arrow","x":0.2,"y":0.3,"x2":0.7,"y2":0.8,"label":"YOU 2"}
]
```

## Acceptance test in ChatGPT

1. Check `https://estampes-mcp.onrender.com/version` shows **m0.4.0** and `ui://estampes/visual-surface-v040.html`.
2. Refresh the Estampes MCP tool definitions in ChatGPT's installed plugin management interface if the new tool is not shown.
3. In a new conversation, ask:

   **使用 Estampes 的 present_visual 工具，開啟 landscape 畫布，在太陽上標一個點。**

4. The widget should show **v0.4.0**, landscape scene, and AI mark.
5. Click the **點選** tool and select the house. Use **框選** to drag around the tree. Click **把標註傳給 GPT**.
6. Confirm the widget reports tool validation **and** the user selection appears as a new user message, with ChatGPT referencing its coordinates.
7. Resize the browser and repeat with **箭頭** to verify positioning.

Run `npm test` on the server to exercise geometry, existing number line, the new MCP tools/resources and the UI script contract.

## Unverified / future work

- Generic drawing and chat return **were observed working** in ChatGPT on 2026-10-29, but semantic placement and author preservation failed. See [M0.4.1 correction](M0-4-1.md) for the fix under test
- Arbitrary photos or image uploads
- Annotation persistence across turns or devices
- Direct access to images retrieved by native ChatGPT image search
- Precise VLM image grounding or semantic object segmentation
- Keyboard-only coordinate input and assistive-technology parity
- Authentication/rate limiting for the public endpoint

**Privacy:** The hosted server is still unauthenticated. Do not send personal or confidential images or data during this proof of concept.

## Versioning

UI resources are cache keyed. M0.4 uses a fresh `ui://` address while leaving the number-line resource intact. Do not change an existing `ui://` resource's HTML/JS when publishing a breaking update; issue a new URI.
