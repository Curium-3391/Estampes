# Estampes M0.4.4 — Show model evidence to the human

M0.4.3 returned three PNG MCP blocks from inspect_visual, and the model could describe visual details, but **no inline image appeared in the user's ChatGPT transcript**. The data tool did not advertise an MCP Apps UI template.

M0.4.4 binds that same inspect_visual tool to \`ui://estampes/visual-evidence-v044.html\` via \`_meta.ui.resourceUri\`. No second model call is required: a single inspect_visual invocation should both return original/annotated/cropped PNGs to the model **and** open a ChatGPT iframe containing the image viewer.

Viewer tabs show:
- Blue-marked full image (default)
- Pristine whole image
- Unmarked magnified crop

The UI consumes the actual MCP image content blocks through \`ui/notifications/tool-result\`, without any remote image fetch. It also reads the provided tool input for scene/focus metadata; a retry button uses the MCP Apps \`tools/call\` bridge if the first result is missing. The image content is not put into structuredContent (which remains small).

This fix does not create image recognition: the model still owns semantic interpretation; Estampes only processes and visualizes pixels and geometry. This milestone still only uses the three built-in SVG demo scenes.

## Test

1. Verify \`/version\` returns \`m0.4.4\` and \`visualEvidenceResourceUri: ui://estampes/visual-evidence-v044.html\`.
2. Refresh tool discovery in ChatGPT and start a fresh chat.
3. Call \`inspect_visual(scene=landscape,imageId=demo:landscape,revision=svg-v1,focus={type:point,x:0.82,y:0.49})\`.
4. Confirm the **Estampes · Visual Evidence** widget appears with the blue-marked scene, and switching to the original and cropped image works.
5. Confirm the model answers based on image content.
6. If the viewer fails, note whether the widget is absent or merely shows \`宿主未提供三個 PNG\`; the latter indicates a host tool-result bridge issue.

CI must pass \`npm test\` and \`node --check server.js\`. Inline preview is still host-dependent and is not verified until visually observed in ChatGPT.
