# Estampes M0.4.8 — Deployment hardening and maintenance

No change to the visual interaction model of M0.4.7. This release addresses
operational issues found while reviewing the repository.

## Changes

- **Optional access key.** `ESTAMPES_ACCESS_KEY` gates `/mcp` (`?key=` or
  Bearer). Off when unset, so existing connectors keep working until a key is set.
- **Rate limit** per client IP on `/mcp` (`ESTAMPES_RATE_LIMIT_PER_MIN`, default 120).
- **CORS allowlist** via `ESTAMPES_CORS_ORIGINS` (default `*`, unchanged).
- **Reproducible installs.** `package-lock.json` is committed; Render and CI use `npm ci`.
- **Single version source.** All version strings and versioned `ui://` URIs
  derive from `package.json`. Widget HTML uses the `__ESTAMPES_VERSION__` placeholder.
- **Legacy viewer payload.** `present_visual_evidence` now returns its three
  base64 PNGs in the result's `_meta["estampes/images"]` (widget-only) instead
  of `structuredContent`, which the model also reads. The widget still accepts
  the old `structuredContent.images` shape.
- Legacy `ui://` URI registrations collapsed into one list; the widget's
  remaining "藍色標記全圖" caption now matches the neutral focus colour.
